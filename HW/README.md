# Homework

Assignments are published in this folder as `01RAD_ExNN_HW.ipynb` together with the corresponding exercise (a copy also sits in `code/`).

## How to submit

1. Fork the course repository `https://github.com/francji1/01RAD`.
2. Solve the assignment in a copy of the notebook and save it into this folder as `01RAD_ExNN_HW_<Surname>.ipynb`, for example `01RAD_Ex01_HW_Novak.ipynb`. One file per student or team; for a team join the surnames with an underscore, for example `01RAD_Ex01_HW_Novak_Svoboda.ipynb`.
3. Open a pull request against the `main` branch of `francji1/01RAD` by the deadline.

## Deadline

Each homework is due on **Sunday of the week in which it was assigned (23:59)**, that is six days after the exercise. The exercises are on Mondays, so the solutions are in before the next exercise, where one of them is discussed at the beginning. When an assignment states a different deadline or asks for team work, the assignment wins.

| Homework | Form | Deadline |
|---|---|---|
| HW01, HW02, HW03 | individual | Sunday of the same week |
| HW04 | team of 2–3 students, one pull request per team | Sunday 1 November 2026, 23:59 |

Keep the file name pattern and do not change other files in the pull request. In particular, never save your work over the assignment `01RAD_ExNN_HW.ipynb`: in Colab use *File → Save a copy in GitHub* and choose your own file name, and check the *Files changed* tab of your pull request before submitting. If the notebook is larger than a few MB, clear the largest outputs before submitting.

With the next exercise one selected student solution is published here as `01RAD_ExNN_HW_solution_student.ipynb`; a reference solution `01RAD_ExNN_HW_solution_ai.ipynb` is added only when the submitted solutions leave something to correct.
